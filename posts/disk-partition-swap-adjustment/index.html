虚拟机磁盘分区与Swap调整实战

2026-05-07

VMware下扩展Ubuntu虚拟机根目录分区指南

概述

本文针对虚拟机磁盘空间不足场景，详细记录了通过调整分区表、交换分区和文件系统扩展Ubuntu虚拟机根目录的完整操作流程。核心目标是通过重新划分磁盘空间，实现根文件系统容量的扩展，同时确保交换分区的正常挂载。操作涉及分区表修改、UUID重用等高风险操作，务必提前备份整个虚拟机镜像。

核心操作流程

一、前期准备

  1. 确认磁盘信息

    df -h           # 查看当前文件系统使用情况
fdisk -l /dev/sda  # 列出当前分区表结构

    记录交换分区（swap）的Blocks数值（如示例中的1046528），若交换分区与根分区位于不同磁盘则无需记录。

  2. 虚拟机磁盘扩容

    • 在VMware虚拟机设置中，通过"硬盘"->“实用工具"扩展磁盘最大容量（如从10.7GB扩展至15GB）
    • 重要提示：虚拟机需处于关机状态才能修改磁盘大小

二、分区表调整

  1. 关闭系统并进入救援模式

    shutdown -h now  # 关机
# 启动时进入救援模式或Live CD环境

  2. 分区表操作

    fdisk /dev/sda
# 操作步骤：
1. 输入 p 查看当前分区表
2. 输入 d 删除原有分区（先删除 sda1 再删除 sda2）
3. 输入 n 创建新主分区（sda1 从 2048 起始）
4. 输入 n 创建新主分区（sda2 作为交换分区）
5. 输入 t 修改分区类型（将 sda2 类型改为 82）
6. 输入 w 保存分区表

  3. 内核识别新分区

    partprobe  # 或 kpartx -a /dev/sda

三、交换分区处理

  1. 获取原始UUID

    awk '/swap/ { print $1 }' /etc/fstab
# 示例输出：UUID=8bb62351-4436-47df-92fe-af2865f03461

  2. 交换分区重建

    swapoff -a  # 关闭所有swap
dd if=/dev/zero of=/dev/sda2 bs=1M count=512  # 清空分区
mkswap -U <UUID> /dev/sda2  # 用原始UUID重建swap
swapon -a  # 挂载新swap

四、文件系统扩展

  1. 在线扩容文件系统

    resize2fs /dev/sda1  # 自动扩展到分区最大容量

  2. 验证扩容结果

    df -h  # 观察根分区容量变化

关键注意事项

  1. 风险控制

    • 分区表修改前必须备份整个虚拟机镜像
    • 操作过程中避免意外断电或中断
    • 确保虚拟机处于关机状态进行磁盘扩容

  2. UUID处理方案

    • 方案一：直接覆盖新分区UUID（如文中方法）
    • 方案二：修改/etc/fstab文件，写入新UUID
    • 两种方案均需确保swap分区重建后验证： 
      swapon --show  # 检查swap是否正常挂载

  3. 兼容性说明

    • 本方案适用于VMware虚拟化环境，物理机操作需谨慎
    • 若使用LVM逻辑卷管理，可采用lvextend等替代方案
    • resize2fs工具要求文件系统类型为ext2/ext3/ext4

  4. 版本差异

    • 不同Linux发行版的swapoff/mkswap工具可能存在参数差异
    • 部分系统可能需要安装util-linux包获取完整工具链

操作验证

完成所有操作后，建议进行以下验证：

  1. 检查磁盘使用情况： 
    df -hT  # 查看文件系统类型和容量
  2. 验证swap状态： 
    free -m  # 确认swap空间已恢复
  3. 系统稳定性测试：
    • 进行内存密集型操作验证swap功能
    • 观察系统运行是否出现I/O错误

附录：常见问题

Q1：扩容后系统无法启动？

  • 检查BIOS/UEFI中磁盘引导顺序
  • 确认MBR引导记录未被破坏
  • 使用Live CD检查分区表结构

Q2：resize2fs报错"Filesystem is mounted”

  • 确保文件系统未被挂载（需进入救援模式）
  • 或使用resize2fs -p /dev/sda1强制在线扩容

Q3：新swap分区未生效？

  • 检查/etc/fstab是否包含新UUID
  • 验证swapon --all命令执行结果
  • 使用dmesg | grep swap查看内核日志

本操作指南基于VMware虚拟化环境和Ubuntu系统验证，实际操作时请根据具体环境调整参数。建议在测试环境中先行演练，确保掌握操作流程后再进行生产环境操作。
