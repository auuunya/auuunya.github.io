PostgreSQL 常用命令与操作指南

概述

本文整理了 PostgreSQL 数据库连接、操作、备份恢复及用户管理的常用命令，涵盖数据表管理、事务处理及导入导出方法。适用于日常数据库维护、开发调试及自动化脚本编写场景。

数据库连接与基础操作

连接数据库

使用 psql 命令行工具连接 PostgreSQL 数据库：

psql -U username -d dbname

若需指定主机和端口：

psql -U username -h host -p port -d dbname

数据库管理

  • 创建数据库 
    CREATE DATABASE dbname;
  • 列出所有数据库 
    \l
  • 删除数据库 
    DROP DATABASE dbname;
  • 切换数据库 
    \c dbname

数据表管理

表结构操作

  • 查看所有表 
    \dt
  • 创建表 
    CREATE TABLE table_name (
  column1 datatype,
  column2 datatype
);
  • 查看表结构 
    \d table_name
  • 修改表结构
    • 添加列： 
      ALTER TABLE table_name ADD COLUMN column_name datatype;
    • 修改列类型： 
      ALTER TABLE table_name ALTER COLUMN column_name TYPE new_datatype;
    • 重命名表或列： 
      ALTER TABLE old_table_name RENAME TO new_table_name;
ALTER TABLE table_name RENAME COLUMN old_column TO new_column;
  • 删除表 
    DROP TABLE table_name;

数据操作

增删改查

  • 插入数据 
    INSERT INTO table_name (column1, column2)
VALUES (value1, value2);
  • 查询数据 
    SELECT column1, column2 FROM table_name WHERE condition;
  • 更新数据 
    UPDATE table_name
SET column1 = value1, column2 = value2
WHERE condition;
  • 删除数据 
    DELETE FROM table_name WHERE condition;

约束与索引

添加约束

  • 主键约束 
    ALTER TABLE table_name ADD CONSTRAINT constraint_name PRIMARY KEY (column_name);
  • 外键约束 
    ALTER TABLE table_name ADD CONSTRAINT constraint_name
FOREIGN KEY (column_name) REFERENCES other_table(other_column);

索引管理

  • 创建索引 
    CREATE INDEX index_name ON table_name (column_name);
  • 删除索引 
    DROP INDEX index_name;

数据备份与恢复

导出数据库

使用 pg_dump 导出数据库到 SQL 文件：

pg_dump dbname > dbname_backup.sql

恢复数据库

  • 导入 SQL 文件 
    psql -U username -d dbname -f /path/to/backup.sql
  • 使用 pg_restore 恢复自定义格式备份 
    pg_restore -U username -d dbname /path/to/backup.dump

pg_restore 常用选项

选项 描述
-v 显示详细恢复过程
-j n 启用并行恢复（提升大文件恢复速度）
-s 仅恢复表结构
-a 仅恢复数据
--clean 删除目标数据库中已存在的对象后重建

注意事项

  • pg_restore 仅适用于自定义格式（如 .dump），普通 SQL 文件需用 psql 恢复。
  • 恢复前需确保目标数据库已存在，或通过 psql 先创建。

用户管理

创建与授权

  • 创建用户 
    CREATE USER username WITH PASSWORD 'password';
  • 授予权限 
    GRANT ALL PRIVILEGES ON DATABASE dbname TO username;

删除用户

DROP USER username;

事务处理

  • 开启事务 
    BEGIN;
  • 提交事务 
    COMMIT;
  • 回滚事务 
    ROLLBACK;

其他实用命令

  • 查看连接信息 
    \conninfo
  • 查看 PostgreSQL 版本 
    SELECT version();
  • 查看数据库配置 
    SHOW ALL;
  • 查询表所有数据 
    SELECT * FROM table_name;

导入 SQL 文件的多种方式

1. 命令行工具 psql

psql -U postgres -d mydb -f /path/to/backup.sql

2. 图形化工具 pgAdmin

  1. 连接数据库后，右键目标数据库 → Query Tool
  2. 点击 打开文件 图标加载 SQL 文件
  3. 按 F5 执行脚本

3. 恢复自定义格式备份

pg_restore -U postgres -d mydb /path/to/backup.dump

注意事项与边界说明

  1. 权限问题

    • 导入/恢复操作需使用具备足够权限的用户（如 postgres）。
    • 容器化部署时（如 Docker），需确保卷挂载路径权限正确（参考 container-database 相关配置）。

  2. 备份格式差异

    • .sql 文件为纯文本格式，适合跨版本恢复；
    • .dump 文件为自定义格式，需用 pg_restore 操作，支持更复杂的恢复选项。

  3. 数据一致性

    • 恢复时若目标数据库非空，使用 --clean 选项会删除已有对象，需提前备份。

  4. 容器环境适配

    • 在容器中运行 PostgreSQL 时，需通过 -v 挂载数据卷，避免容器重启导致数据丢失（详见 container-database）。

通过上述命令和操作，可高效完成 PostgreSQL 的日常管理任务。具体场景下（如高并发、大表操作），建议结合索引优化、事务控制及定期备份策略，以保障数据安全与性能。
